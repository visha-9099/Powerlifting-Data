🏋️‍♂️ Powerlifting Data
This repository contains a comprehensive dataset on powerlifting performances, including lifter statistics, competition results, and strength metrics. 
The dataset is perfect for athletes, coaches, data analysts, and strength enthusiasts looking to explore trends in powerlifting, performance analysis, 
and training insights.

📌 Features
📊 Dataset Overview
Lifter Information: Name, gender, age, weight class.
Competition Details: Event name, date, location, federation.
Lifts Recorded:
Squat (kg)
Bench Press (kg)
Deadlift (kg)
Total (kg) (sum of all lifts)
Wilks Score: Strength-to-bodyweight ratio for fair comparisons.
Equipment Used: Raw, single-ply, multi-ply.
Federation Rules: Variations in judging and weight classes.

🏆 Key Insights from the Dataset
What is the average squat, bench, and deadlift for different weight classes?
How do men and women compare in terms of strength-to-bodyweight ratio?
Which federations have the highest Wilks scores?
Are heavier lifters always stronger?
